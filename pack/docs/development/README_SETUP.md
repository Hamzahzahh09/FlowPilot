# Cara memakai paket ini
1. Salin semua isi paket ke root repo (LICENSE, .kiro/, docs/development/).
2. Pastikan .kiro TIDAK ada di .gitignore.
3. git add . && git commit -m "chore: add MIT license, Kiro steering, roadmap" && git push
4. Jalankan prompt di docs/development/KIRO_PROMPTS.md satu per satu (mulai dari nomor 1).
